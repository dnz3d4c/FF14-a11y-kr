- 기존 저장소가 원본 파일에 직접 넣어 두고 있던 개선분 셋을 버리고 `upstream-reports/`에 옮겨 적었다. 원본의 결함은 우리가 고치지 않는다 (D-06).
- 한국어 작업 스킬 셋을 923줄에서 476줄로 줄였다. 사건 서술을 빼고 규칙만 남겼으며, 지우면 사라지는 판정은 `korean/lexicon.json`과 `docs/dev/`로 옮겼다.
- 배포 창구를 정했다. 기존 저장소는 `repo.json` 하나만 남기고 실물은 새 저장소 릴리스에 둔다. 이미 깐 사용자가 아무것도 안 해도 새 판을 받는다 (D-08).
- 조립하다가 원본 v5.95의 인코딩 손상을 찾았다. `YesNoLabels`의 일본어 라벨 둘이 물음표로 바뀌어 있다. 고치지 않고 `upstream-reports/`에 적었다.
- 파서를 두 번 넓혀 못 읽던 자리 43곳을 13곳으로 줄였다. 보간 자리 안의 따옴표에서 24곳, 중첩 삼항을 펴서 6곳이다. **"못 읽음"을 파서의 한계로만 다뤄 왔는데 그것이 사용자가 듣던 영어였다.** 고아로 잡혀 있던 `Levequests` 둘도 결함이 아니라 파서가 못 읽은 것이어서, 펴자마자 물렸다.
- 열린 41곳을 옮겨 미적용을 45곳에서 4곳으로 줄였다. 대장 842행, 적용 862곳이다. 남기는 넷은 어순이 걸리는 `CounterConnector`, 낱말이 없는 `TargetDirection`·`GaugeAttunement`, 게임에 낱말이 없는 `DCSelected`다.
- 대장 값이 보간 자리 안에 escape 없는 따옴표를 담을 수 있게 됐다. 그래서 대장이 처음으로 컴파일을 깨뜨릴 수 있게 되어, 중괄호 균형·중첩 리터럴 정합·`references` 대조 셋을 막는 장치로 넣었다.
- 용어 도구가 `Addon` 하나에서 `Action`·`Pet`·`Status`까지 넷을 읽는다. 소환사 게이지 용어 일곱이 전부 `Action`에 있었다. **Addon에 없다는 것은 "게임에 없다"가 아니라 "이 도구가 보는 범위 밖"이었다** — 기존 `not_found` 셋도 그렇게 사실이 아니었다.
