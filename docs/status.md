## 번역 잔량

**2026-09-04, v5.95 실측값이다.** 조립 도구가 낼 때마다 바뀌고 `tools/docs-check`가 산출물과 대조하므로, 어긋난 채로 두면 검사가 빨개진다. 출발점은 미적용 13곳·못 읽음 43곳이었다.

| 이름 | 값 | 뜻 |
|------|-----|-----|
| 적용 | 984곳 (대장 950행) | 대장의 한국어가 실제로 들어간 자리 |
| 고아 | 3행 | 대장에는 있는데 소스에서 못 만났다. 업스트림이 그 문장을 고쳤다는 신호 |
| 미적용 | 4곳 | 영어로 나가고 모드가 로그에 남긴다 |
| 못 읽음 | 10곳 | 갈림길인 줄은 알지만 파서 손 밖이라 위 숫자에 없다 |
| 튜플 사전 | 3,023건 | 조립 도구가 아예 보지 않는다 |

**판정은 잔량으로 한다.** "몇 행 반영"이 아니라 **영어로 나가는 자리가 몇 곳인가**를 본다. 지금은 4 + 10 + 3,023이다.

**적용이 862곳에서 984곳으로 는 것은 사각지대 둘을 연 결과다.**

`ColorNamer.cs`가 `Loc.IsGerman`에 붙인 별칭 `De`로 갈리는 **104곳**이 표식 밖이라 적용에도 미적용에도 안 잡히고 있었다. 캐릭터 생성의 색상 묘사가 통째로 영어로 나가면서 어느 숫자에도 안 나타난 것이다. 표식에 `De`를 더해 열고 색상 낱말 96행을 올렸다. **낱말 자체는 사용자 귀 판정을 기다린다** — 게임에 색상 이름이 없어서 모드가 짓는 말이다.

방위 낱말 **18곳**은 언어별 배열을 통째로 고르는 자리라 파서가 배열 이름만 보고 낱말은 못 봤다. `{direction}` 홀을 가진 한국어 문장이 27건 있는데 그 홀에 `North`가 들어가고 있었다. 배열 셋을 원소별 갈림길로 펴서 열었고 낱말은 게임 한국어판에서 왔다 — Addon 102104 북부터 102111 북서까지가 연속된 행이고 차례가 모드 배열과 같다. **차례가 어긋나도 컴파일되고 어느 검사도 안 걸리므로 인게임에서 들어야 한다.**

남는 미적용 4곳은 손대지 않기로 정한 자리다.

| 자리 | 왜 남기나 |
|------|-----------|
| `CounterConnector` | 어순이 뒤집힌다. `UIReaderService.TryParseSpokenProgress`가 이 문장을 다시 읽어 사냥수첩을 알아보므로, 읽는 쪽을 같이 고쳐야 한다. 번역이 아니라 코드 변경이다 |
| `TargetDirection` | 독일어와 영어가 글자까지 같고 옮길 낱말이 없다 |
| `GaugeAttunement` | 같은 이유. `{type} {count}` 형식뿐이다 |
| `DCSelected` | `Worlds:`의 한국어 낱말이 게임 데이터에 없다. 지어내지 않는다 — `terms.json`의 `not_found`에 근거가 있다 |

못 읽음 10곳은 이어붙이기 5와 리터럴이 아님 5다. 조립 보고가 멤버 이름과 모양으로 지목하므로 사람이 무엇을 봐야 하는지가 보고 안에 있다. 리터럴이 아닌 다섯은 전부 캐릭터 생성 튜플 사전을 읽는 자리다.

고아 3행은 `Aethernet`·`FATEs`·`Place`다. 업스트림이 고친 문장이라 대장을 맞춰야 한다. `Levequests` 둘은 고아가 아니었다 — 대장 키가 소스와 글자까지 같은데 파서가 중첩 삼항을 못 읽었을 뿐이라, 펴자마자 물렸다.

### 깔고 재는 법

    uv run python tools/pack/pack.py
    dist\FF14AccessibilityInstaller-KR.exe --install --skip-vnavmesh

**개발용 자리에 깔지 않는다.** 정식 자리와 상호 배타적이라 같은 모드가 두 번 적재되고, 무엇보다 들리는 것과 낸 것이 갈라져 귀 판정이 무효가 된다. `--install`은 릴리스를 타지 않고 EXE 옆의 zip을 쓰므로 방금 만든 것이 그대로 깔린다.

깐 뒤에 잰다 — 설치본 DLL의 해시가 `dist/FF14Accessibility.zip` 안의 것과 같은지, `devPlugins`에 우리 것이 없는지, 매니페스트의 `InstalledFromUrl`이 새 저장소 주소인지. 게임이 떠 있으면 `Tolk.dll`을 잡고 있어서 반만 깔리므로 끈 상태에서 돌린다.

## 원본에 보낼 것

`upstream-reports/`에 파일 다섯이 있다. 셋은 재포팅에서 버린 개선분이고 둘은 새로 찾은 원본 결함이다.

새로 더한 것은 **장소 유형이 언제나 독일어로 발화되는 결함**이다. `TypeLabel`을 식별용으로 독일어로 두는 것은 의도인데 그 값이 발화 문장에 그대로 들어간다. 대장의 고아 `Aethernet`·`Place`가 그 자국이고, `place-type-spoken-twice.md`와 **한 변경으로 같이 닫힌다.**

## 못 푼 것

**교차 리뷰 결과를 종결하지 못하고 있다.** `codex-review`가 `.json`만 남기고 `.md`가 안 생기는데 종결 스크립트가 `.md`를 요구한다. 손으로 돌린 것과 훅이 자동으로 돌린 것 둘 다 그렇다. 이번 재포팅의 리뷰가 전부 미처결로 쌓인다.

**액션 넷이 Node.js 20을 대상으로 해서 러너가 경고를 낸다.** `actions/checkout@v4` 계열이고 우리 잘못이 아니지만, 언젠가 강제로 끊기면 CI가 통째로 선다.

## CI에서만 드러난 결함 둘 — 기록해 둔다

로컬 실증과 교차 리뷰가 둘 다 지나쳤고 **실제로 푸시해야만** 나왔다.

- 트리거가 `branches: [main]`인데 기본 브랜치가 `master`라 워크플로가 아예 안 돌았다. 문법이 맞아 아무 검사도 안 걸렸다.
- 윈도 러너의 파이썬 stdout이 cp1252라 우리 도구가 한국어를 내는 순간 죽었다.

**공통점은 "저장소 밖 또는 러너 안의 사실"이라는 것이다.** 로컬에서 명령을 그대로 돌리는 실증으로는 원리적으로 안 잡힌다. 새 워크플로를 더할 때는 반드시 한 번 밀어 보고 결과를 확인한다.
