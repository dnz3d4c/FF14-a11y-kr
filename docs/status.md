미적용이 13에서 45로 는 것은 회귀가 아니다. 파서가 넓어지면서 못 읽던 자리가 옮겨 온 것이다 — 보간 자리 안의 따옴표에서 24곳, 중첩 삼항을 펴면서 8갈래다. **옮겨 온 자리는 `Loc.Pick`을 타므로 번역 전이라도 인게임 로그에 자기 이름을 적는다.**

## 못 푼 것

**교차 리뷰 결과를 종결하지 못하고 있다.** `codex-review`가 `.json`만 남기고 `.md`가 안 생기는데 종결 스크립트가 `.md`를 요구한다. 손으로 돌린 것과 훅이 자동으로 돌린 것 둘 다 그렇다. 이번 재포팅의 리뷰가 전부 미처결로 쌓인다.

**액션 넷이 Node.js 20을 대상으로 해서 러너가 경고를 낸다.** `actions/checkout@v4` 계열이고 우리 잘못이 아니지만, 언젠가 강제로 끊기면 CI가 통째로 선다.

## CI에서만 드러난 결함 둘 — 기록해 둔다

로컬 실증과 교차 리뷰가 둘 다 지나쳤고 **실제로 푸시해야만** 나왔다.

- 트리거가 `branches: [main]`인데 기본 브랜치가 `master`라 워크플로가 아예 안 돌았다. 문법이 맞아 아무 검사도 안 걸렸다.
- 윈도 러너의 파이썬 stdout이 cp1252라 우리 도구가 한국어를 내는 순간 죽었다.

**공통점은 "저장소 밖 또는 러너 안의 사실"이라는 것이다.** 로컬에서 명령을 그대로 돌리는 실증으로는 원리적으로 안 잡힌다. 새 워크플로를 더할 때는 반드시 한 번 밀어 보고 결과를 확인한다.
