# FF14 접근성 모드 (한국 서버용) 사용 안내

파이널 판타지 14를 한국 서버에서 스크린 리더로 플레이할 수 있게 하는 모드입니다. 이 문서는 모드 설치, 사용법을 다룹니다.

## 1. 준비물

### 1) 직접 준비해야 하는 것

- 운영체제: Windows
- FINAL FANTASY XIV 한국 서버 클라이언트
- 한국 서버 계정
- 스크린 리더 **NVDA**

### 2) 한국 서버 계정 만들기

한국 서버는 전용 계정을 사용합니다. 글로벌 서버 계정으로는 접속할 수 없습니다.

계정은 파이널 판타지 14 한국 공식 홈페이지에서 만들 수 있습니다.

https://www.ff14.co.kr

[회원가입]에서 가입 유형을 고른 다음 본인인증을 진행합니다. 본인인증은 휴대폰 인증과 아이핀 인증 중에서 선택할 수 있습니다.

### 3) 설치 프로그램이 내려받는 것

넷은 설치 프로그램이 자동으로 내려받습니다. 직접 준비하지 않아도 됩니다.

- **Microsoft .NET 10 Desktop Runtime x64** — 모드가 게임 안에서 실행되는 데 필요합니다
- **KR Dalamud 업데이터** — 모드를 게임에 붙이는 프로그램입니다
- **vnavmesh** — 자동 이동 기능이 사용하는 모드입니다
- **던전 경로 파일** — `던전` 분류가 사용합니다

넷 다 내려받기 전에 묻는 대화상자가 표시됩니다. .NET 10은 이미 설치되어 있으면 묻지 않고 넘어갑니다.

.NET 10을 설치할 때는 윈도 권한 요청 창이 한 번 표시됩니다. [예]를 선택하면 설치가 진행됩니다.

vnavmesh를 설치하지 않아도 자동 이동 관련 기능 외 모드 기능은 동작합니다.

## 2. 설치

### 1) 받는 것

https://github.com/dnz3d4c/FF14-a11y-kr/releases/latest 에서 최신 버전을 받습니다.

**`FF14AccessibilityInstaller-KR.exe` 하나만 받으면 됩니다.** 설치 프로그램이며, 모드 본체는 설치할 때 함께 내려받습니다.

### 2) 설치 순서

#### ① 게임 종료

설치 전 게임이 실행중인지 확인 후 게임을 종료합니다.

#### ② 설치 프로그램 실행

받은 `FF14AccessibilityInstaller-KR.exe`에서 Enter를 누릅니다.

※ 서명이 없는 프로그램이라 Windows SmartScreen 경고가 뜰 수 있습니다. [추가 정보] 링크를 클릭하면 [실행] 버튼이 나타납니다.

#### ③ 언어 선택

[언어 선택 / Choose language] 창이 열립니다. 기본으로 한국어가 선택되어 있습니다. Enter를 누르면 다음 화면으로 넘어갑니다.

#### ④ 설치 시작

설치 프로그램 창에서 [설치 / 업데이트] 버튼에 초점이 위치합니다.

진행 상황 편집창에는 설치 프로그램의 작업 과정이 기록됩니다. 화살표 키로 내용을 읽을 수 있습니다.

[설치 / 업데이트] 버튼을 실행하면 필요한 것을 차례로 묻습니다.

#### ⑤ .NET 10 설치 여부 고르기

이미 설치되어 있으면 묻지 않고 진행 상황에 `.NET 10 데스크톱 런타임이 설치되어 있습니다`가 남습니다.

설치되어 있지 않으면 `.NET 10 데스크톱 런타임을 지금 내려받아 설치하시겠습니까?`가 표시됩니다. [예]를 실행하면 내려받아 설치하며, 이때 윈도 권한 요청 창이 한 번 표시됩니다. 설치가 끝나면 `.NET 10 데스크톱 런타임을 설치했습니다.`가 남습니다.

#### ⑥ KR Dalamud 업데이터 설치

KR Dalamud 업데이터를 받을지 확인하는 대화상자가 표시됩니다. [예] 버튼을 실행해 업데이터를 설치합니다.

#### ⑦ vnavmesh 설치 여부 고르기

- `자동 이동은 vnavmesh 플러그인을 설치해야 동작합니다.`
- `vnavmesh 플러그인을 설치하지 않아도 자동 이동을 제외한 나머지 기능은 동작합니다.`
- `vnavmesh를 설치하시겠습니까?`

[예]를 실행하면 플러그인을 설치합니다. [아니오]를 고르면 `vnavmesh를 건너뛰었습니다.`가 남습니다.

#### ⑧ 던전 경로 파일 내려받기 여부 고르기

- `던전 분류는 던전을 지나는 길의 지점을 이동 순서대로 알려 줍니다.`
- `경로 파일은 AutoDuty 프로젝트 저장소에서 내려받습니다.`
- `경로 파일이 없으면 던전 분류가 나타나지 않습니다.`
- `경로 파일을 내려받으시겠습니까?`

[예]를 실행하면 경로 파일을 내려받습니다. `경로 파일 254개를 넣었습니다.`처럼 개수가 표시됩니다.

[아니오]를 고르면 `경로 파일을 건너뛰었습니다. 던전 분류는 나타나지 않습니다.`가 남습니다. 이때도 파일을 넣을 폴더는 만들어 두므로, 나중에 직접 구한 경로 파일을 넣을 수 있습니다.

#### ⑨ 업데이터에서 [업데이트 확인] 누르기

KR Dalamud 업데이터 창이 열립니다. Tab 키로 [업데이트 확인] 버튼을 찾아 실행합니다.

업데이트시 몇 분 정도 소요됩니다.

#### ⑩ 결과 확인

접근성 설치 프로그램의 결과 표시 편집창에서 설치 결과를 확인합니다.

- `== 결과 ==`
- `접근성 모드: ...`
- `vnavmesh: ...`
- `경로 파일(던전 분류): ...`
- `플레이 바로가기: ...`
- `플러그인을 등록하고 활성화했습니다.`

각 줄이 `새로 설치`, `업데이트`, `최신 버전`, `건너뜀`, `설치됨` 중 하나로 끝나면 설치에 성공한 것입니다. `실패:`로 시작하는 줄이 있다면 프로그램 설치를 다시 진행합니다.

바탕화면과 시작 메뉴에 [FF14 접근성 모드로 플레이] 바로가기가 만들어집니다. 게임을 실행할 때 이 바로가기를 사용합니다.

### 3) 업데이트 방법

`FF14AccessibilityInstaller-KR.exe`를 다시 실행해 [설치 / 업데이트] 버튼을 누릅니다. 다음에 게임을 켤 때 새 판이 올라옵니다.

설치 프로그램 자신의 새 버전이 있으면 받을지 먼저 물어봅니다. [아니오]를 고르면 지금 버전 그대로 설치가 이어지고, 모드 본체는 어느 쪽을 골라도 최신 판으로 설치됩니다.

**[예]를 고르면 설치 프로그램 창이 한 번 닫힙니다.** `이 창은 지금 닫히고 잠시 뒤 자동으로 다시 실행됩니다`가 들린 다음 실제로 닫히고, 새 버전이 자동으로 다시 실행되면서 대화 상자가 뜹니다. [확인]을 누르면 설치가 끝까지 진행되고, [설치 / 업데이트] 버튼을 다시 누르지 않아도 됩니다.

### 4) 게임이 업데이트된 뒤

게임이 업데이트되어 버전이 올라가면 **KR Dalamud가 새 버전을 지원할 때까지 모드가 실행되지 않습니다.**

접속해도 `FF14 Accessibility 버전 ... 준비됨.`이 들리지 않는 상태가 됩니다. 설치가 망가진 것이 아니므로 모드를 다시 설치하지 않아도 됩니다.

#### ① 새로운 업데이트가 있는지 확인하기

**게임이 꺼져 있는 상태에서** KR Dalamud 업데이터를 실행합니다. Win+R을 누르고 아래를 붙여넣으면 됩니다.

%LOCALAPPDATA%\KR-Dalamud-Updater\app\Dalamud.Updater.exe

업데이터 창에서 [업데이트 확인] 버튼을 누릅니다. 새 업데이트가 있으면 내려받아 적용되고, 그 뒤로는 3장의 실행 순서를 그대로 따르면 모드가 다시 실행됩니다.

### 5) 제거

#### ① 모드만 지우기

Win+R을 누르고 아래를 붙여넣으면 설치된 플러그인 폴더가 열립니다.

%APPDATA%\XIVLauncherKR\installedPlugins

`FF14Accessibility` 폴더를 지웁니다.

vnavmesh도 설치했다면 아래를 붙여넣어 열리는 폴더에서 `vnavmesh` 폴더를 삭제합니다.

%APPDATA%\XIVLauncherKR\devPlugins

#### ② Dalamud까지 삭제하기

**다른 Dalamud 플러그인을 사용하고 있으면 이 단계는 진행하지 않습니다.** 아래 폴더를 삭제하면 KR Dalamud와 함께 설치된 플러그인이 모두 지워집니다.

%APPDATA%\XIVLauncherKR

KR Dalamud 업데이터까지 삭제하려면 아래 폴더도 삭제합니다.

%LOCALAPPDATA%\KR-Dalamud-Updater

#### ③ 바로가기와 실행 파일 지우기

바탕화면과 시작 메뉴의 [FF14 접근성 모드로 플레이] 바로가기를 삭제합니다. 바로가기가 실행하는 파일은 아래 폴더에 있습니다.

%LOCALAPPDATA%\FF14Accessibility

#### ④ 남는 것

설치할 때 만들어진 `DALAMUD_RUNTIME` 사용자 환경 변수는 위 폴더들을 지워도 남습니다. .NET이 설치된 자리를 가리키는 값이라 그대로 두어도 다른 프로그램에 영향이 없습니다. 지우려면 윈도의 환경 변수 설정에서 사용자 변수 `DALAMUD_RUNTIME`을 삭제합니다.

.NET 10 데스크톱 런타임은 다른 프로그램도 사용하므로 그대로 두는 것을 권장합니다. 지우려면 윈도의 [설정 > 앱 > 설치된 앱]에서 `Microsoft Windows Desktop Runtime`을 제거합니다.

## 3. 게임 실행

### 1) 실행 순서

#### ① 바로가기 실행

바탕화면의 [FF14 접근성 모드로 플레이] 바로가기를 실행합니다. 시작 메뉴에도 같은 이름으로 있습니다.

이 바로가기 하나가 게임과 KR Dalamud 업데이터를 함께 실행합니다. 게임을 실행할 때 윈도 권한 요청 창이 표시되므로 [예]를 선택합니다.

#### ② 로그인

런처로 로그인 후 게임 시작 버튼을 눌러 게임을 실행합니다.

모드는 이 다음에 자동으로 붙습니다. 업데이터 창에서 따로 누를 버튼은 없습니다.

#### ③ 모드가 실행됐는지 확인

모드가 실행되면 게임 실행시 `FF14 Accessibility 버전 5 점 88 준비됨.`처럼 음성이 출력됩니다.

들리지 않는 경우는 6장 3절에서 다룹니다.

#### ⑤ 사용할 수 있는 키 확인하기

`Ctrl+F1`을 누르면 지금 상황에서 사용할 수 있는 키와 명령을 들을 수 있습니다.

### 2) 안내 언어 고르기

- `/acc lang ko` — 한국어(기본값)
- `/acc lang en` — 영어
- `/acc lang de` — 독일어
- `/acc lang auto` — Windows 언어를 따라감

### 3) 설정 메뉴

`Shift+F9`로 설정 메뉴를 열 수 있습니다.

- `소리` — 항목이 열셋입니다. `길안내 신호음`, `기술 준비됨`, `HP MP 신호음`, `전투 경고 전용 음성`은 켜고 끕니다. `길안내 신호음 음량`, `경유지와 도착 알림음`, `기술 준비됨 음량`, `HP MP 신호음 음량`, `장판 경고음 음량`, `경고 음성 음량`은 **음량**을 조절하고 값이 0이면 소리가 나지 않습니다. `경고 음성 속도`와 `전투 경고 음성`은 경고를 읽는 목소리와 빠르기를 고르고, `장판 경고음`은 장판 경고에 쓸 소리를 고릅니다. 각 소리가 무엇을 나타내는지는 4장 2절과 4장 4절에 있습니다
- `안내` — 방향 안내, 대상 변경, 대상 HP, 적 기술 시전, 지도 표식, 오류 메시지, 알림 메시지를 켜고 끕니다
- `로그 채널` — 채널별로 읽어 줄지를 켜거나 끕니다.
- `로그 탭` — 게임 탭을 따라가는 로그 시스템을 사용할 때만 나옵니다
- `로그 시스템` — 두 로그 시스템 중 하나를 고릅니다. 이 행은 지금 고른 것을 달고 들립니다(`로그 시스템: 기존, 고정 채널`)

조작 키는 다음과 같습니다.

- 숫자패드 8 또는 위쪽 화살표 — 위로
- 숫자패드 2 또는 아래쪽 화살표 — 아래로
- 숫자패드 6, 숫자패드 0, 오른쪽 화살표 — 고르기, 한 단계 안으로
- 숫자패드 4 또는 왼쪽 화살표 — 한 단계 이전으로
- 숫자패드 마침표, Delete, ESC — 메뉴 닫기
- Home, End — 목록의 처음, 끝으로 이동
- 글자나 숫자 키 — 글자로 시작하는 항목으로 건너뛰기

## 4. 키

키만 한자리에 모은 목록은 [단축키 목록](KEYS.ko.md)에 있습니다. 키를 다른 키로 바꾸는 방법은 7장에 있습니다.

### 1) 대상 찾기

- **Page Down** — 다음 대상 알려 주고 지정하기
- **Page Up** — 이전 대상 알려 주고 지정하기
- **Ctrl+Page Down** — 다음 분류로 옮기기
- **Ctrl+Page Up** — 이전 분류로 옮기기

분류는 스물두 개이고 `Ctrl+Page Down`을 누를 때마다 변경된 분류 이름을 읽습니다.

전체, NPC, 상인, 적, 아군, 플레이어, 사물, 임무, 퀘스트 NPC, 퀘스트 사물, 퀘스트 적, 채집 지점, 돌발 임무, 토벌 대상, 낚시터, 전체 임무, 던전, 에테라이트, 퀘스트 목표, 받을 수 있는 퀘스트, 길드 의뢰, 경유지입니다.

딥 던전에서는 전체, 방, 보물상자, 석탑, 적입니다. 석탑은 부활 석탑과 전송 석탑 둘을 함께 담습니다.

※ `던전`은 딥 던전에서는 나타나지 않습니다. 딥 던전의 분류는 위의 다섯 개로 정해져 있습니다.

#### 던전 분류와 경로 파일

`던전` 분류는 던전을 지나는 길의 지점을 **이동 순서대로** 음성 출력합니다. 사물이나 적처럼 가까운 것부터 음성 출력하는 분류와 다릅니다.

- 지점의 종류는 `조작`, `보스`, `보물상자`, `점프` 넷입니다. 종류가 안 붙은 지점은 그 자리에 `경로 지점`을 넣어 음성 출력합니다
- 분류를 고르면 `던전 지점 8개. 지금 3번.`처럼 음성 출력합니다. 뒤의 번호는 지금 서 있는 자리에서 가장 가까운 지점이라 던전을 얼마나 지났는지 알 수 있습니다
- 지점 사이는 `Page Down`과 `Page Up`으로 넘깁니다. 처음 넘길 때는 가장 가까운 지점에서 시작하고, 그 다음부터는 누를 때마다 다음 번호로 넘어갑니다
- 지점마다 `3번 8개 중: 조작, 12미터, 북쪽.`처럼 번호를 먼저 음성 출력하고 종류와 거리와 방향을 이어 붙입니다
- 지점을 고른 뒤 `숫자패드 3`을 누르면 자동 이동이 그 지점까지 걸어갑니다
- 마지막 지점에서는 `경로의 마지막 지점.`을 음성 출력합니다. 던전은 보스로 끝나므로 목록이 끝났다는 뜻이 아니라 보스 앞에 있다는 뜻입니다

이 분류가 답하는 것은 이 방의 어느 문인가가 아니라 여기서 어디로 가야 하는가입니다. 지점과 지점 사이가 평균 40미터를 넘어 방 안을 짚을 만큼 촘촘하지 않습니다.

**분류가 나타나려면 해당 던전의 경로 파일이 있어야 합니다.** 설치 프로그램이 내려받아 두므로 보통은 따로 할 일이 없습니다. 파일이 없으면 `해당 던전 경로 파일 없음.`을 음성 출력합니다.

경로 파일은 다음 폴더에 들어갑니다.

%APPDATA%\XIVLauncherKR\pluginConfigs\FF14Accessibility\DungeonPaths

※ KR Dalamud 업데이터에서 프로필 위치를 변경했다면 `XIVLauncherKR` 부분이 그 위치로 바뀝니다. 설치 프로그램의 결과 표시 편집창에 실제 경로가 표시됩니다.

직접 구한 경로 파일을 넣을 때는 셋을 지켜야 합니다.

- **파일 이름이 `(지역번호) 이름.json` 형식이어야 합니다.** `(1036) Sastasha.json`이 그 예입니다. 형식이 다른 파일은 조용히 건너뛰어지므로, 넣었는데 분류가 안 나타나면 이름부터 확인합니다
- **한 지역에 파일이 여럿 있으면 하나만 사용하고 나머지는 사용하지 않습니다.** 어느 것을 사용하는지는 알려 주지 않으므로, 지역마다 파일을 하나씩만 두는 것이 좋습니다
- **게임을 실행한 상태에서 파일을 넣으면 바로 반영되지 않습니다.** 다른 지역으로 이동했다가 돌아오거나 게임을 다시 실행합니다

※ `경유지`에는 지역 출구가 포함됩니다.

#### 이동과 길안내 소리가 나타내는 것

**길안내 신호음**은 목표가 어느 쪽에 있는지 알려 줍니다. **길안내를 받는 동안에만 울립니다.**

- 목표가 왼쪽에 있으면 소리도 왼쪽에서 나고 오른쪽이면 오른쪽에서 납니다
- 앞뒤는 소리의 높이로 구분합니다. 뒤로 돌아갈수록 낮아집니다
- 목적지에 **가까워질수록 소리가 커집니다**
- **목표 쪽을 정확히 향하면 소리가 가운데로 오고 느려집니다.** 좌우 6도 안에 들어오면 맞은 것으로 보고, 다시 어긋난 것으로 보는 것은 10도를 벗어났을 때입니다. 두 각도가 다른 것은 경계에서 소리가 흔들리는 것을 막기 위해서입니다
- **방향이 맞는 순간 짧은 확인음이 한 번 납니다.** 소리가 서서히 바뀌는 것을 귀로 골라내지 않아도 그 소리로 알 수 있습니다
- **방향이 맞아 갈수록 소리 간격이 느려집니다.** 완전히 어긋났을 때 0.4초이고 방향이 맞으면 0.95초까지 벌어집니다
- **소리가 아예 멈추는 것은 다른 뜻입니다.** 목표가 없거나, 길안내를 받고 있지 않거나, 이동이 끝났다는 뜻입니다
- **대상 종류마다 소리가 다릅니다.** 적, NPC, 사물, 채집 지점, 지역 이동, 에테라이트, 퀘스트 목표, 임무 입구, 그리고 장판에서 빠져나갈 안전한 자리까지 아홉 가지입니다. 무엇을 향하고 있는지 따로 듣지 않아도 소리로 구분됩니다
- 적 소리는 낮고 두 번 치는 소리이고, **장판 회피 자리는 그보다 더 낮고 세 번 칩니다.** 가장 급한 소리입니다

※ v5.89까지는 목표를 정면으로 향하면 소리가 멈추는 방식이었습니다. v5.90부터 멈추지 않고 가운데에서 느려지는 방식으로 바뀌었으며, 이름도 `길안내 신호음`이 되었습니다.

**길안내**를 켜면 직접 걸어가는 동안 장애물을 피해 갈 방향을 알려 줍니다. 지나야 할 지점마다 소리가 나고, 지금 보고 있는 쪽을 기준으로 어느 쪽으로 가야 하는지 말해 주며, 도착하면 도착 소리가 납니다.

**경로 미리 듣기**는 걷지 않고 경로만 음성 출력합니다. `에테라이트까지 경로, 62미터: 북 방향 25미터 …`처럼 구간마다 방향과 거리를 이어서 말합니다.

**오르내리는 높이**는 그 경로 안내 끝에 이어 붙습니다. `오르막 6미터.`처럼 음성 출력하고, 오르막과 내리막이 둘 다 있으면 `오르막 6미터, 내리막 3미터.`가 됩니다. 경로 미리 듣기와 자동 이동과 길안내 셋 다 붙습니다.

- **1.5미터부터 음성 출력합니다.** 문턱이 오르막과 내리막에 따로 걸리므로 오르막 6미터에 내리막 0.8미터인 길은 오르막만 들립니다
- **오르막과 내리막을 상쇄하지 않습니다.** 계단을 올랐다 다시 내려오면 합이 0이 되는데, 그 경우를 알리려고 만든 안내라서 합치지 않습니다
- **길의 어디에서 오르내리는지는 음성 출력하지 않습니다.** 모드가 높이는 재지만 그 자리는 모릅니다

**발자취**는 길 정보에 빠져 있는 구간을 한 번 직접 걸어서 기록해 두는 기능입니다. 나중에 자동 이동이 같은 자리에서 막히면 기록해 둔 발자취를 따라갑니다.

※ **길안내, 자동 이동, 따라가기는 한 번에 하나만 켜집니다.**

※ **토벌수첩이 열려 있고 마물 줄에 초점이 있으면 `숫자패드 3`이 다른 일을 합니다.** 자동 이동 대신 그 마물을 찾아 주는데, 가까이 있으면 그리로 걸어가고 없으면 어디에 사는지 말해 줍니다.

※ `+`는 숫자패드의 `+`가 아니라 일반 자판의 `+`입니다.

※ **`N`은 한국 클라이언트에서 제작수첩과 겹칩니다.** 자세한 것은 6장 1절에 있습니다.

게임이 원래 쓰는 키 중 자주 함께 쓰는 것은 `F`(대상 쪽으로 돌기)와 `W`(전진)입니다.

#### 전투 소리가 나타내는 것

**HP와 MP는 소리로도 나갑니다.** 남은 양이 소리가 나는 위치로 바뀝니다.

- 가득 차 있으면 오른쪽, 절반이면 가운데, 다 떨어졌으면 왼쪽에서 납니다. 10퍼센트 단위로 옮겨 갑니다
- 소리의 높이가 올라가면 회복한 것이고 내려가면 피해를 입거나 소모한 것입니다
- **HP와 MP는 소리 자체가 달라서 한꺼번에 나도 구별됩니다.** HP는 높고 둥근 소리, MP는 낮고 유리 같은 소리입니다
- **HP가 25퍼센트 아래로 내려가면 HP 소리가 떨립니다.** MP 소리는 떨리지 않습니다

**적을 지정하면 짧은 소리가 납니다.** 대상의 HP는 백분율로 말해 줍니다. 게임이 적의 HP를 숫자로 보여 주지 않기 때문입니다.

**범위 경고**를 켜면 예고된 범위 안에 서 있는 동안 반복해서 소리가 나고, 빠져나오면 소리가 나지 않습니다.

**기술 준비됨**은 재사용 대기가 끝났을 때 소리와 이름으로 알려 줍니다. `/acc cd`로 켜고 끕니다.

※ 범위 경고가 기본으로 꺼져 있는 이유는 경고할 범위의 모양을 알아내는 방식이 아직 게임 안에서 완전히 확인되지 않아서입니다. 전투 중에 틀린 경고가 나는 것이 경고가 없는 것보다 나쁘다고 보았습니다.

※ 입찰 창으로 초점을 옮기는 것은 키를 눌러야 합니다.

### 6) 기술 메뉴

- **Ctrl+F9** — 첫 단축바 읽기. 1번부터 0번 키에 할당된 값을 음성으로 출력합니다
- **Ctrl+숫자패드 0** — 기술 메뉴 열고 닫기

기술 메뉴가 열려 있는 동안 숫자패드는 메뉴를 다루는 데만 쓰입니다. 아래 키는 원래 게임에서 이동과 확인·취소에 쓰이는 것이라 메뉴가 열려 있는 동안에는 게임에 전달되지 않습니다.

- **숫자패드 8, 숫자패드 2** — 목록 넘기기
- **숫자패드 4, 숫자패드 6** — 목록 바꾸기. 목록은 다섯입니다. 기술, 아이템, 퀘스트 아이템, 일반 기술, 탈것입니다
- **숫자패드 0** — 고르기. 기술을 고르면 놓을 수 있는 키 목록으로 넘어갑니다. 거기서 숫자패드 8과 2로 키를 고르고 숫자패드 0을 한 번 더 누르면 그 키에 놓입니다
- **숫자패드 마침표** — 한 단계 이전으로 가기, 또는 메뉴 닫기

### 7) 로그 되읽기

- **Alt+Page Up** — 이전 채널로 옮기기
- **Alt+Page Down** — 다음 채널로 옮기기
- **Shift+Page Up** — 고른 채널에서 더 오래된 줄 읽기
- **Shift+Page Down** — 고른 채널에서 더 새로운 줄 읽기
- **Shift+Home** — 채널의 맨 처음으로 가기 (신규 로그 시스템에서만 동작)
- **Shift+End** — 채널의 맨 끝으로 가기 (신규 로그 시스템에서만 동작)
- **Alt+Home** — 이전 로그 탭으로 옮기기 (신규 로그 시스템에서만 동작)
- **Alt+End** — 다음 로그 탭으로 옮기기 (신규 로그 시스템에서만 동작)
- **Enter** — 방금 읽은 줄에 같은 채널로 답장하기

채널을 옮기면 채널 이름과 그 안에 쌓인 줄 수를 말해 줍니다. 채널은 대화, 말하기, 외치기, 파티, 연합 파티, 귓속말, 자유부대, 시스템, 전리품입니다.

**답장이 되는 채널은 넷입니다.** 말하기, 파티, 자유부대, 귓속말입니다. 외치기와 연합 파티에서는 그 채널로 보낼 수 없다고 말해 주고, 대화·시스템·전리품에서는 아무 일도 일어나지 않습니다. 되읽기를 마지막으로 만진 지 30초가 지나면 채널을 바꾸지 않고 지금 채널 그대로 입력란이 열립니다.

※ `Alt+Home`과 `Alt+End`로 로그 탭을 바꾸는 것은 모드가 새로 만든 기능이라, 게임의 단축키 설정에서는 이 두 키를 찾을 수 없습니다.

### 9) 카드 대결

- **Ctrl+Shift+F4** — 판 읽기
- **Ctrl+Shift+F5** — 내 패 읽기

### 10) 플러그인 목록

- **Shift+F1** — 다음 플러그인 알려 주기
- **Shift+F2** — 이전 플러그인 알려 주기
- **Shift+F12** — 고른 플러그인의 설정 열기

### 11) 진단

- **Ctrl+F5** — 열린 창의 내부 구조를 바탕 화면에 파일로 저장하기. 어떤 창이 왜 안 읽히는지 문제를 파악하는 데 도움이 됩니다

### 12) 게임 키와 겹치는 것

게임이 사용하는 키 개수는 게임 실행시 음성 출력합니다.

- **Page Up과 Page Down**은 카메라 확대·축소를 겸합니다
- **Ctrl+End**는 카메라 설정 저장을 겸합니다
- **숫자패드 5**는 카메라를 대상 쪽으로 돌리는 기능을 겸합니다. 이 키를 누를 때 카메라까지 같이 움직이지 않도록 모드가 이 키를 받고 게임에는 넘기지 않습니다

한국 클라이언트에서 방향 안내를 켜고 끄는 `N`이 제작수첩을 여는 키와 겹칩니다.

## 5. 명령어

키 대신 명령어로 쓸 수 있는 기능이 있습니다. 대화 입력란에 그대로 입력하면 됩니다.

- `/acc help` — 도움말 알려 주기
- `/acc nav` — 대상까지의 방향과 거리 말하기
- `/acc set` — 지금 지정한 대상을 계속 따라다니며 안내하기
- `/acc clear` — 추적 중인 대상 지우기
- `/acc near` — 가까이 있는 대상 나열하기
- `/acc status` — HP와 MP 말하기
- `/acc ui` — 열려 있는 메뉴 읽기
- `/acc win` — 초점이 있는 창 알려 주기
- `/acc keys` — 게임 단축키 설정을 바탕 화면에 저장하기
- `/acc stop` — 말하기 멈추기
- `/acc fish` — 이 지역의 낚시터 알려 주기
- `/acc fishhere` — 지금 서 있는 자리를 낚시터로 기억하기
- `/acc fishobj` — 50미터 안의 사물을 가까운 순으로 훑어 기록에 남기기. 음성으로는 찾은 개수만 말합니다. 낚시터를 못 찾을 때 원인을 알아보는 진단용입니다
- `/acc gather` — 이 지역의 채집 지점 알려 주기
- `/acc gathergo` — 가장 가까운 채집 지점으로 이동하기
- `/acc trails` — 이 지역에 기록해 둔 발자취 나열하기
- `/acc trail del <번호>` — 기록해 둔 발자취 지우기. 번호는 `/acc trails`가 말해 주는 그 번호입니다
- `/acc cd` — 기술 준비됨 안내 켜고 끄기. `/acc cooldowns`도 같습니다
- `/acc soundtest` — 모드가 쓰는 소리를 차례로 들려주기. 4장 2절과 4장 4절의 설명과 짝지어 들으면 됩니다
- `/acc lang ko` — 모드 안내 메시지 언어 바꾸기. `ko`, `en`, `de`, `auto`를 사용할 수 있습니다
- `/acc dump <창 이름>` — 창의 구조를 바탕 화면에 저장하기

## 6. 문제 해결

### 1) `N` 키가 제작수첩을 같이 엽니다

`N`은 방향 안내를 켜고 끄는 키인데 **한국 클라이언트에서는 `N`이 제작수첩 키입니다.** 그래서 방향 안내를 켜고 끌 때마다 제작수첩이 같이 열립니다. 설정 파일에서 키를 변경할 수 있습니다.

### 2) 그 밖에 자주 겪는 문제

#### ① 자동 이동이 안 될 때

- `자동 이동을 쓸 수 없음. vnavmesh 플러그인이 없거나 불러오지 못함.` — vnavmesh가 설치되지 않았습니다. 설치 프로그램을 실행해 설치할 수 있습니다
- `길 정보 불러오는 중, 42 퍼센트. 잠시 뒤 다시 시도 필요.` — vnavmesh는 동작하고 있습니다. 지역에 처음 들어가면 길 정보를 새로 만드느라 몇 분 걸립니다. 숫자 자리에는 그때의 진행률이 들어갑니다
- `길 정보가 아직 준비 안 됨. 잠시 뒤 다시 시도 필요.` — vnavmesh는 동작하지만 이 지역의 길 정보가 아직 없습니다

#### ② 캐릭터 생성에서 영어로 안내될 때

캐릭터 생성의 **얼굴과 머리 모양 묘사는 아직 한국어로 옮기지 못했습니다.** 영어로 출력됩니다.

#### ③ 설치 프로그램이 KR Dalamud 업데이터를 받지 못할 때

진행 상황 영역에 아래 같은 줄이 남았다면 설치 프로그램이 인터넷에서 업데이터를 가져오지 못한 것입니다.

- `GitHub에 연결하지 못했습니다: ... 업데이터는 직접 받아야 합니다.`
- `GitHub 응답이 없습니다. 업데이터는 직접 받아야 합니다.`
- `최신 버전에 "Portable" 압축이 없습니다. 업데이터는 직접 받아야 합니다.`

앞의 둘은 잠시 뒤에 설치 프로그램을 다시 실행하면 대개 해결됩니다. 세 번째까지 나오면 [github.com/MiqoKR/kr-dalamud-updater](https://github.com/MiqoKR/kr-dalamud-updater)의 최신 릴리스에서 이름에 `Portable`이 들어간 압축 파일을 받아 아래 폴더에 풉니다.

%LOCALAPPDATA%\KR-Dalamud-Updater\app

### 3) 모드가 활성화되지 않을 때

게임 접속 시 `FF14 Accessibility 버전 ... 준비됨.`이 들리지 않으면 아래를 차례로 확인할 수 있습니다.

- ① **NVDA가 켜져 있는지** 확인합니다
- ② **KR Dalamud 업데이터가 실행되어 있는지** 확인합니다. 게임만 따로 켜면 모드가 붙지 않습니다
- ③ 설치 프로그램을 다시 실행해 진행 상황 영역에 `실패:`로 시작하는 줄이 있는지 확인합니다. .NET 10이 있는지도 이때 함께 확인됩니다

## 7. 키 설정

### 1) 키 이름을 부르는 방식이 세 가지입니다

같은 키를 세 곳이 서로 다르게 부릅니다. 이 차이를 모르면 설정 파일에서 키를 바꿀 수 없기 때문에 먼저 짚습니다.

- **이 문서**는 로마자로 적습니다 — `Ctrl+F1`, `Shift+F9`, `Page Down`, `ESC`
- **모드가 말할 때**는 한글로 읽습니다 — `컨트롤 F1`, `페이지 다운`, `숫자패드 3`
- **설정 파일에 적는 값은 독일어입니다** — `Strg+F1`, `BildAb`, `Numpad3`

설정 파일에서 **Ctrl, Shift, Alt는 영어로 적어도 됩니다.** 그 뒤에 오는 키 이름만 독일어이고 쓸 수 있는 이름이 정해져 있습니다.

| 이 문서 표기 | 설정 파일에 적는 값 |
|--------------|---------------------|
| Ctrl | `Strg` 또는 `Ctrl` |
| Shift | `Umschalt` 또는 `Shift` |
| Alt | `Alt` |
| Page Up / Page Down | `BildAuf` / `BildAb` |
| End | `Ende` |
| Delete | `Entf` |
| Home | `Pos1` |
| Insert | `Einfg` |
| ESC | `Escape` |
| Enter | `Return` |
| Tab | `Tab` |
| 스페이스 | `Leertaste` |
| 백스페이스 | `Rücktaste` |
| 위쪽 화살표 / 아래쪽 화살표 | `Up` / `Down` |
| 왼쪽 화살표 / 오른쪽 화살표 | `Left` / `Right` |
| F1~F12 | `F1`~`F12` |
| 숫자패드 숫자 | `Numpad0`~`Numpad9` |
| 숫자패드 마침표 | `NumpadKomma` |
| 글자 | `A`~`Z` |
| 숫자 | `0`~`9` |
| 쉼표, 마침표, 빼기, 더하기 | `,` / `.` / `-` / `+` |

즉 `Ctrl+Page Down`은 설정 파일에 `Strg+BildAb`로 적습니다.

**이 표에 없는 이름을 적으면 해당 키는 동작하지 않습니다.**

※ 숫자패드에 할당된 단축키(숫자패드 3, 숫자패드 5 등)를 사용하려면 넘락을 켜야 합니다. 설정 메뉴는 화살표 키로도 다룰 수 있어서 넘락이 꺼져 있어도 됩니다. 기술 메뉴는 숫자패드만 받으므로 넘락이 필요합니다.
