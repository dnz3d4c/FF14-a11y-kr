# 열린 결함

**파일 하나가 결함 하나다.** 이름은 `W-NN.md`이고 번호는 재사용하지 않는다.

## 닫히면 파일을 지운다

이것이 이 디렉토리의 전부다. 기존 저장소는 현황판 한 파일에 결함을 절로 쌓았고, 그래서 1,748줄 중 1,317줄이 "알려진 결함" 한 절이 됐다. 그 절의 소절 48개 중 19개는 이미 닫혔는데 아무도 안 지웠다.

**닫을 때 지우기 쉬운 단위를 만드는 것이 핵심이다.** 파일 하나면 `git rm` 한 번이고 이력은 git이 갖는다. 현황판이 이력을 겸할 이유가 없다.

끝난 것은 `docs/changelog.md`에 한 줄로 남는다. 그 한 줄에서 파일 이름을 부르면 `git log`로 전문을 되찾을 수 있다.

## 한 파일에 담는 것

    # W-NN 무엇이 잘못됐나

    **상태**: 열림 | 막힘
    **증상**: 사용자가 겪는 것 한 줄

    ## 무엇이 일어나나
    ## 왜 그런가 (아는 만큼만)
    ## 닫히는 조건

**닫히는 조건을 안 적으면 닫을 수가 없다.** 무엇을 보면 끝났다고 할 수 있는지를 열 때 적는다.

**아는 만큼만 적는다.** 원인을 모르면 모른다고 적는다. 짐작을 원인 자리에 적으면 다음 사람이 그것을 근거로 쓴다.

## 원본 결함은 여기 오지 않는다

원본의 결함은 `upstream-reports/`가 갖는다. 우리가 고칠 것과 원본이 고칠 것을 섞으면 무엇을 기다리는지 못 읽게 된다.
