# 원본에 보낼 것

원본의 결함을 우리가 고치지 않는다. 고쳐 놓으면 새 판을 얹을 때마다 그 자리가 부딪히고, 무엇이 원본이고 무엇이 우리 것인지 이력이 못 읽는다. 여기에 적고 원본에 보고한다.

한국어판에만 필요한 것은 여기 오지 않는다. 그것은 `korean/`·`kr/`·`replace/`·`graft/`가 갖는다. 여기 오는 것은 **언어와 무관하게 원본에도 이로운 것**뿐이다.

## 파일 하나가 사안 하나다

닫히면 파일을 지운다. 목록 안의 한 항목이면 지우기가 번거로워 남고, 남으면 무엇이 열려 있는지 못 읽게 된다.

| 상태 | 뜻 |
|------|-----|
| 초안 | 우리가 관찰했고 아직 원본에 안 보냈다 |
| 보고함 | 원본에 냈다. 링크를 적는다 |
| 반영됨 | 원본이 받아들였다. **이 파일을 지운다** |
| 기각됨 | 원본이 거절했다. 까닭을 적고 지운다 |

## 여기 적는 것은 한국어다

원본은 독일어로 개발된다. 보고할 때 번역하고, 여기 남기는 기록은 우리가 읽을 것이므로 한국어로 쓴다. 우리 판단의 근거가 사라지지 않게 하는 것이 이 디렉토리의 목적이다.

## 재포팅에서 버린 개선분

기존 저장소는 원본 로직을 직접 고쳐 놓았고, 그래서 새 판마다 그 자리가 부딪혔다. 재포팅하면서 그 변경을 전부 버렸다. 버린 것이 사라지지 않게 여기 옮겨 적는다.
